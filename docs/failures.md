# Отладка и диагностика

| Воспроизведение | Наблюдение | Обработка или исправление |
|---|---|---|
| Старт проверки покрытия в сетевой песочнице | VSTest не подключился к тестовому процессу | Повтор на разрешённом loopback, Coverlet сформировал отчёт |
| Запрос /health при удалённой таблице Lessons во временной тестовой SQLite | Запрос к таблице выдаёт SqliteException | 503 ProblemDetails без имени таблицы или стека |
| Старая версия при повторе перехода | Два клиента могли бы изменять один объект | 409 и предложение обновить карточку |
| Пустое расписание | Средний срок нельзя делить на ноль | averageDays = null, в WPF прочерк |
| CSV с одной недопустимой строкой | Частичный импорт затрудняет безопасный повтор | Валидация до сохранения, список ошибок по физическим строкам |
| Ошибочный пароль | 401 без подробностей о существовании аккаунта | В журнале событие отказа, форма показывает понятное сообщение |

В Visual Studio полезны условная точка останова в SchoolStore.Transition по id, просмотр входных значений и версии, стек для вызова LessonRules.Transition, отображение PracticalLesson с DebuggerDisplay. Вставить снимки «Локальные», «Контрольные значения», «Стек вызовов» и «Вывод». Встречный обмен модулем статистики выполняется с партнёром.
