# Совместимость

| Среда или формат | Проверка | Фактический результат |
|---|---|---|
| Windows x64, сборка 26200, .NET SDK 10.0.402 | Release WPF + API | Сборка успешна |
| Конфигурация совместимости .NET 8 | Release шести проектов и живой HTTPS API | Сборка без ошибок и предупреждений, 63 проверки API. На стенде отсутствует IDE Visual Studio 2022. |
| Путь с кириллицей | Публикация и распаковка Windows x64 | ZIP сформирован и распакован |
| ru-RU, en-US, de-DE | Разбор суммы 1500,50 и 1500.50 | Все 5 положительных параметров приняты; варианты с группировкой отклонены |
| UTC и ISO 8601 | Сериализация JSON/XML и локальное время WPF | Проверено наличие зоны UTC в экспорте, WPF переводит время в локальное |
| CSV UTF-8 с BOM, запятая и точка с запятой | Кириллица, кавычки и разделители | Пройдены модульные тесты и живой импорт |
| Excel с английским разделителем списка | Импорт через «Данные → Из текста/CSV» | Порядок описан в руководстве |
| Отдельный компьютер без установленного .NET | Автономный ZIP | Отдельная физическая машина или VM отсутствовала; автономный ZIP проверяется на текущем Windows |

Публикация win-x64 содержит собственную среду выполнения. Созданные пользователем БД и журналы сохраняются в LocalAppData.
