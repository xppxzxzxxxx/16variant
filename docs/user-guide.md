# Руководство пользователя

1. Распакуйте ZIP для Windows x64 целиком и откройте DrivingSchool.Desktop.exe. Введите логин и пароль из README.
2. Менеджер открывает «Ученики» и добавляет ФИО, телефон и необязательную почту. В «Занятия» создаёт карточку, выбирает ученика, указывает упражнение, место встречи, инструктора, начало и сумму. Дата и время вводятся по местному времени Windows в формате ДД.ММ.ГГГГ ЧЧ:ММ.
3. Для подтверждения откройте смену статуса после заполнения инструктора и времени. После занятия выберите «Проведено» и введите фактическое время завершения. Если занятие перенесено или пропущено, укажите причину.
4. Инструктор видит свой список и свою статистику. Администратор может дополнительно просмотреть вкладку пользователей.
5. Введите часть имени или упражнения и выберите статус. Для выгрузки текущей выборки выберите формат и папку. Для CSV в Excel используйте «Данные → Из текста/CSV», кодировку UTF-8 и разделитель «точка с запятой».
6. Для импорта используйте файл с заголовком Name;Phone;Email. При ошибках исправьте указанные строки и повторите импорт.
7. При конфликте версии обновите список и снова откройте карточку. При ошибке соединения перезапустите клиент и проверьте журналы в %LOCALAPPDATA%/DrivingSchool/logs. Кнопка «Выйти» открывает форму входа.

Места для снимков: форма входа; занятие и смена статуса; главное окно инструктора; статистика; ошибки CSV.
