# Безопасность

| Проверка | Реализация и свидетельство |
|---|---|
| HTTPS к loopback | Desktop создаёт сертификат и сверяет его SHA-256. Smoke использует собственный краткоживущий сертификат и тестовый порт. |
| Ключ JWT | По умолчанию случайный на запуск. В Development имеется UserSecretsId. В иных средах ключ допускается передать через Jwt__Key. |
| Хеши паролей | PBKDF2 SHA-256, уникальная соль, сравнение фиксированного времени. Указанные в README пароли предназначены только для учебных записей. |
| Частота входа | После пяти неверных попыток за минуту запрос получает 429, проверено ApiContractTests. |
| Проверка роли | Привилегии проверяет сервер. Для инструктора фильтр назначения работает до получения карточек и метрик. |
| Отзыв сеанса | После выхода последующие запросы с тем же JWT получают 401. |
| Ошибки | ProblemDetails. Причина доменного отказа доступна клиенту, внутреннее исключение отражается общим сообщением. |
| SQLite и CSV | EF Core параметризует запросы. CSV выгружается с экранированием и защитой текстовых ячеек от формул. |
| NuGet | Выполнен аудит прямых и транзитивных пакетов шести проектов. |

Для учебного локального профиля API рассчитан на loopback. Демо-учётные записи и хранение списка отзыва в памяти ограничивают область использования стендом практики.
