# Требования к варианту 16

Источник требований — строка 16 и общие правила Приложения А методических указаний УП.02. Реестр предназначен для менеджера, инструктора и администратора автошколы. В карточку входят ученик, упражнение, место встречи, инструктор, начало, сумма, примечания и технические данные записи.

| ID | История и критерий приёмки |
|---|---|
| F01 | Сотрудник входит под своей ролью. Верные данные открывают рабочее окно, выход возвращает форму и отзывает токен. |
| F02 | Менеджер регистрирует ученика и создаёт занятие. Ученик обязателен, новая запись получает статус «Запланировано». |
| F03 | Сотрудник меняет статус из допустимого списка. Сервер отклоняет недопустимый переход, пустые обязательные поля и устаревшую версию. |
| F04 | Инструктор видит свои занятия и собственную статистику. Чужая карточка и переход возвращают 404. |
| F05 | Сотрудник находит занятия по ID, упражнению, месту, имени и телефону ученика. Поиск по кириллице регистронезависим, фильтр по статусу применяется одновременно. |
| F06 | Менеджер импортирует UTF-8 CSV. Ошибки показываются с номерами строк, файл с ошибками отклоняется целиком. |
| F07 | Менеджер сохраняет текущую выборку в CSV, JSON или XML. |
| F08 | Сотрудник видит общее число, число открытых, итоги по каждому статусу, общую сумму, сумму проведённых и средний срок. |
| F09 | Администратор открывает список учебных учётных записей без паролей. |
| N01 | .NET 10, Windows x64, локальный HTTPS, SQLite и автоматическая начальная миграция. |
| N02 | Журналы клиента и сервера помогают диагностировать отказ. Ответы API не раскрывают стек сервера. |
| N03 | Автономный клиент запускается из распакованного архива. Сборка Release проходит анализаторы. |

## Переходы

| Из | В | Условие |
|---|---|---|
| Запланировано | Подтверждено | Назначены существующий инструктор и время начала. |
| Подтверждено | Проведено | Положительная сумма и фактическое время от запланированного начала до текущего момента. |
| Запланировано, Подтверждено | Перенесено | Указана причина. Для нового времени менеджер создаёт отдельное занятие. |
| Запланировано, Подтверждено | Пропущено | Указана причина. |
| Проведено, Перенесено, Пропущено | — | Конечные статусы. Редактирование и переходы закрыты. |
