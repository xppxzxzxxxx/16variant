# Чек-лист WPF

Вход администратора, менеджера, Ивана и Павла проверяет заголовок сеанса, доступные разделы и выход. Неверный пароль проверяется отдельным сценарием с журналом. Два сценария главного окна проверяют поиск кириллицей и выбор статуса «Проведено» на семи демозанятиях. Тесты работают с временной БД.

Для снимков: форма входа, окно менеджера, окно инструктора, карточка и переход, статистика и ошибки импорта. Для ручного показа: создайте ученика, подтвердите занятие и выгрузите текущий фильтр в трёх форматах.
