# Проверки живого API

Прогон Smoke-Api.ps1 выполнен с отдельным процессом Release API, временной SQLite и закреплённым пробным HTTPS-сертификатом. Итог — 63 успешные проверки кодов и содержимого.

| Сценарий | Ожидание | Факт |
|---|---:|---:|
| Health и миграция на новой базе | 200 | 200 |
| Незарегистрированный сеанс читает список | 401 | 401 |
| Вход правильным паролем каждой роли | 200 | 200 |
| Вход с неверным паролем | 401 | 401 |
| Менеджер открывает список пользователей | 403 | 403 |
| Инструктор открывает справочник или выгружает данные | 403 | 403 |
| Корректный и ошибочный CSV | 200 и 400 | 200 и 400 |
| Создание занятия | 201 | 201 |
| Подтверждение без назначения | 400 | 400 |
| Чужая карточка и переход | 404 | 404 |
| Устаревшая версия | 409 | 409 |
| Переход с выполненными условиями | 204 | 204 |
| Фильтр и выгрузка трёх форматов | 200 | 200 |
| Выход и повторный запрос старым токеном | 204 и 401 | 204 и 401 |

В WebApplicationFactory дополнительно проверены системный отказ, ограничитель попыток входа и ограничения полей.
